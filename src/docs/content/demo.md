# Interactive demos

A demo is a series of clickable screenshots that show your product without a signup.

## Install

Share the hosted link, or place it in your page:

```html
<div data-flowpilot="{{PROJECT_ID}}"></div>
<script src="{{ORIGIN}}/flowpilot.js" data-project-id="{{PROJECT_ID}}" defer></script>
```

## Build it

Each **Demo screen** shows a screenshot. Inside it, **Hotspot** blocks are the points people click. Set the position as a percentage across and down the image.

A hotspot goes to the next screen unless you set **Go to screen number**, which lets you create branches. After the last screen, visitors can restart.

Screenshots are stored as images, so remove any private customer data before uploading them.
