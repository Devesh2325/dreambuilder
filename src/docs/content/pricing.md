# Pricing tables

A pricing table shows your plans, on any page.

## Install

```html
<div data-flowpilot="{{PROJECT_ID}}"></div>
<script src="{{ORIGIN}}/flowpilot.js" data-project-id="{{PROJECT_ID}}" defer></script>
```

## Plans

Edit plans under **Details**. Each has a name, price, description and its own button link.

Buttons link to wherever you take payment. FlowPilot doesn't process payments.
