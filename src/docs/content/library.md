# Team library

The library is where your team keeps what it reuses. Open **Template library** in the left menu.

## Sections

A section is a ready-made part of a page, such as a hero, a pricing table or a footer. In the editor for a website or page, open **Add**, then **Sections**. Drag one onto the canvas, or click it to add it below the selected section.

To save your own, select a block, open its **Advanced** tab and choose **Save to team library**. A saved section keeps what it shows right now, with values filled in, so it works in any project. It stops following that project's variables.

## Team templates

There are two ways to make a template:

1. In **Template library**, click **Create template**, choose a type and build it in the editor from sections and blocks.
2. Open any existing project in the editor.

Either way, click **Save as template** at the top of the editor. The template keeps its variables, and today's values become the starting values. Anyone in the workspace can then choose it under **Create new**, fill in the details and get their own copy.

Projects made from a template don't change when the template is deleted. A form's webhook address isn't saved in the template, so set it again in each new project.

## Variables

Open **Variables** in the editor to change any value in one place. **New variable** adds your own, such as a phone number. To use it, select a block and choose **+ Insert a variable** under a text or link field.

## Who can do what

Everyone in a workspace can use the library. Owners, admins and editors can add to it and delete from it. Viewers can't, and the database enforces this.
