# Testimonials

Testimonials show customer quotes, on any page.

## Install

```html
<div data-flowpilot="{{PROJECT_ID}}"></div>
<script src="{{ORIGIN}}/flowpilot.js" data-project-id="{{PROJECT_ID}}" defer></script>
```

## Quotes

Edit quotes under **Details**. Make sure you have permission to use each person's name and words.
