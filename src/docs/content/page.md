# Pages

A page is a single hosted landing page, for a launch, event or campaign.

## Create one

Choose a page template, fill in your details, then publish. It goes live at `{{ORIGIN}}/s/your-address`.

Pages work like one-page websites, without a shared header or footer. Add a navigation block from the **Add** tab if you want one.

Forms placed on a page save their responses to the project. See [form data and webhooks](webhooks).
