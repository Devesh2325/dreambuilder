# Banners

A banner is a message bar pinned to the top or bottom of your site.

## Install

```html
<script src="{{ORIGIN}}/flowpilot.js" data-project-id="{{PROJECT_ID}}" defer></script>
```

## Options

Click an empty part of the canvas to choose top or bottom, which pages it appears on, and how often. Select the banner block to control whether visitors can close it.

A banner covers the page content beneath it instead of pushing it down. If it hides your navigation, use the bottom position.
